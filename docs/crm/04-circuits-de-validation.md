# Circuits de validation

## Règles transversales

Chaque transition enregistre acteur, date, motif, ancien et nouvel état. Les notifications sont minimisées. Le sensible exige deux validations distinctes ; l’auteur ne compte pas comme valideur final de son propre contenu.

## Contribution générale

`draft → submitted → incomplete | under_review → changes_requested | approved | rejected → scheduled | published → unpublished | withdrawn | archived`

| Transition | Acteur/conditions | Motif, notification, audit et retour |
|---|---|---|
| Création `draft` | Contributeur habilité | Version auditée ; auteur seul |
| `draft → submitted` | Auteur ; champs requis | Éditorial notifié ; retrait possible |
| `submitted → incomplete` | Responsable éditorial | Motif obligatoire ; retour draft |
| `submitted → under_review` | Éditorial affecte un relecteur | Affectation auditée ; visibilité limitée |
| `under_review → changes_requested` | Relecteur/éditorial affecté | Demandes précises ; retour draft |
| `under_review → approved/rejected` | Éditorial ; deux habilités si sensible | Décision motivée ; rejet contestable |
| `approved → scheduled/published` | Éditorial ; version figée, droits valides | Audience/date auditées |
| `published → unpublished` | Éditorial ou association dans son périmètre | Motif ; republication après revue |
| `* → withdrawn` | Auteur si permis ou responsable habilité | Non exposé, trace minimale |
| `unpublished/withdrawn → archived` | Responsable habilité | Conservation validée |

## Archive

1. Quarantaine restreinte.
2. Provenance, déposant, propriétaire, auteur, datation et certitude.
3. Droits, consentements, restrictions et crédits.
4. Distinction original/version de consultation ; originaux différés au-delà du MVP.
5. Validation documentaire par le référent.
6. Décision éditoriale séparée, double si sensible.
7. Publication de la seule version autorisée.
8. Correction ou retrait sur demande, contestation ou expiration de droit.

Chaque étape peut revenir en quarantaine. Toute future consultation d’original, modification de droits ou décision est auditée.

## Témoignage

Le dépôt reste restricted. Un affecté vérifie consentement, diffusion, anonymisation, tiers cités et sensibilité. Le responsable éditorial valide l’ordinaire ; deux habilités valident le délicat. Une correction produit une version. Le retrait est facilité et tracé. Tout contenu concernant un mineur est différé jusqu’à validation juridique.

## Actualité ou événement

`draft → review → approved → published → updated | unpublished`

Auteur ou responsable local crée ; relecteur vérifie exactitude, dates, organisateur, audience et mandat ; éditorial approuve. Une communication institutionnelle exige seconde validation et mandat valide. Mise à jour crée une version et, si substantielle, une nouvelle revue. Dépublication motivée et auditée.

## Contenu contesté

`signalement → qualification → retrait préventif éventuel → gel des suppressions → examen → décision → notification → archivage`

| Étape | Acteur/conditions | Retour et audit |
|---|---|---|
| Signalement | Toute personne, canal futur visible | Accusé sans promesse de résultat |
| Qualification | Éditorial ou communautaire | Priorité, risque, conflit d’intérêts |
| Retrait préventif | Habilité ; risque sérieux | Masquage réversible, motif, notification |
| Gel | Responsable affecté | Préserve preuves et versions |
| Examen | Affectés sans conflit | Sources, droits, consentements, droit de réponse |
| Décision motivée | Éditorial ou double validation si sensible | Correction, restriction, maintien ou dépublication |
| Notification | Responsable du dossier | Parties concernées, information minimisée |
| Archivage | Habilité | Décision/preuves nécessaires ; contestation possible |

Le propriétaire intervient seulement pour sécurité ou retrait exceptionnel. Voir [les règles éditoriales](06-regles-editoriales.md).
